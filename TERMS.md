## 1. Description of Service

J'Snaps is a native desktop application designed for screen capture, annotation, and optional cloud sharing. Features include:
- Screen freezing and customizable rectangular area capture.
- On-screen markup tools (drawing, text, shapes, blur/redact, step counters).

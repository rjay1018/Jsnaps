Privacy Policy

Last Updated: October 11, 2026

1. Overview & Core Principles

This Privacy Policy describes how J'Snaps ("we", "our", or "the application") handles user data. J'Snaps is a native desktop screen capture and annotation tool designed with strict privacy and security standards:

  • Zero Telemetry: J'Snaps does not collect, log, track, or sell your personal data, screen contents, usage habits, or analytics.
  • Local-First Processing: All screenshots, drawings, crops, and annotations are rendered and processed solely on your local computer. Nothing leaves your machine unless you explicitly choose to upload an image.

2. Google Drive API & User Data Handling

J'Snaps provides an optional feature allowing users to upload screenshots directly to their own Google Drive account to generate shareable links.

Requested Google OAuth Scope

J'Snaps requests only the following single Google API permission:

https://www.googleapis.com/auth/drive.file

Per-File Access Only: This restricted scope allows J'Snaps to view, create, and manage only the specific files and folders that were created by J'Snaps itself (specifically, the JSnaps folder in your Drive). J'Snaps cannot read, view, list, modify, or delete any of your other existing Google Drive files, photos, or documents.

How Google User Data is Handled

  • Direct Client-to-API Communication: All data transfers occur directly between the local J'Snaps client on your device and Google's official API servers (googleapis.com). Data never passes through or touches any intermediate third-party proxy or developer server.
  • Local Credential Encryption: Your OAuth refresh token is stored strictly on your local device and encrypted using Electron's safeStorage API (backed by Windows DPAPI). It is never transmitted to us or any third party.
  • No Selling of User Data: We never sell, rent, or monetize your personal information or Google user data.
  • No AI Model Training: Google user data accessed by J'Snaps is never used to train, develop, or improve generalized machine learning or artificial intelligence models.

Google API Services User Data Policy Compliance

J'Snaps' use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Alternative Public Sharing (Catbox)

If you choose to use Catbox as your share host (the zero-login default):

  • Images you explicitly choose to share are uploaded to Catbox (catbox.moe) as public files accessible via the generated URL.
  • We strongly recommend using J'Snaps' built-in Blur / Redact tool (hotkey B) to obscure passwords, emails, and sensitive details prior to sharing links publicly.

4. User Control & Data Deletion

  • Revoke In-App: You can disconnect your Google account from J'Snaps at any time by selecting "Sign out of Google Drive" in the desktop system tray menu. This immediately revokes the OAuth token with Google and purges all credentials from your computer.
  • Revoke via Google: You can manage and revoke application permissions at any time via your Google Account Security Dashboard at https://myaccount.google.com/permissions.
  • Deleting Uploaded Files: Because all files uploaded via Google Drive reside directly in your own Google Drive storage under the JSnaps folder, you retain 100% control to view, organize, or permanently delete them at any time from your Google Drive interface.

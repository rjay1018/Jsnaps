2. Description of Application

J'Snaps is an open-source, local-first screen capture and image annotation tool designed for Windows. It provides features including instant screen freezing, pixel-level area selection, drawing tools, blur/redact tools, and voluntary cloud sharing to third-party services (such as Catbox and user-authenticated Google Drive).
